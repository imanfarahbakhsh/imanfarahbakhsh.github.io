01

FRESIS 1.0 — Fluid–Rigid–Elastic Structure Interaction Solver

A monolithic solver for incompressible flow carrying rigid and elastic bodies, built on a full-Eulerian framework and the vorticity–stream function formulation. Fluid, rigid and elastic phases share one fixed grid, so moving and deforming structures need no remeshing — a reproducible, extendable base for problems from sloshing tanks to bio-inspired flows.

  • Software paper — Software Impacts 2023 · doi:10.1016/j.simpa.2023.100537
  • Source code — GitHub
  • Reproducible capsule — Code Ocean
  • Related paper — A full-Eulerian approach for a system of fluid–rigid–elastic structure interaction based on the vorticity–stream function formulation, Fluid Dynamics Research 55 (2023)

02

FEGC 1.0 — Flow Energy Gradient Calculator

Computes the energy gradient function — the ratio of energy gradient across a streamline to that along it — from a two-dimensional velocity field. Filtering its highest values locates the points most prone to the onset of instability or the spread of chaos, demonstrated on Rayleigh–Taylor instability and high-Reynolds cavity flow.

  • Software paper — Software Impacts 2024 · doi:10.1016/j.simpa.2024.100705
  • Source code — GitHub
  • Reproducible capsule — Code Ocean
  • Related paper — Derivation of energy gradient function for Rayleigh–Taylor instability, Fluid Dynamics Research 50 (2018)

03

SPHMPS 1.0 — Smoothed-Particle-Hydrodynamics Multi-Physics Solver

A Lagrangian, mesh-free solver for multi-structure collision problems with large plastic deformation and coupled thermal effects. Developed with E. Oterkus (University of Strathclyde) and applied to material flow in friction stir welding.

  • Software paper — Software Impacts 2024 · doi:10.1016/j.simpa.2024.100640
  • Source code — GitHub
  • Reproducible capsule — Code Ocean
  • Related paper — SPH simulation of pin shape effects on material flow in friction stir welding, J. Peridynamics and Nonlocal Modeling 5 (2023)

04

HOC-Krylov 1.0 — Krylov Subspace Solvers with High-Order Compact Schemes

Solves Poisson’s equation in two dimensions by pairing high-order compact finite-difference stencils with Krylov subspace methods — CG, BiCG, CGS, BiCGSTAB, CR and GMRES — under several sparse storage formats and ILU-family preconditioners, for fast and accurate solutions in CFD and electrostatics.

  • Software paper — Software Impacts 2026 · doi:10.1016/j.simpa.2026.100820
  • Source code — GitHub
  • Reproducible capsule — Code Ocean
  • Related paper — A survey on the performance of Krylov subspace methods in high-order compact schemes for Poisson’s equation, Annals of Applied Mathematics 41 (2025)
